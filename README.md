# Esraa Ahmed Abdelmoneim — Portfolio

Portfolio presenting Esraa Ahmed Abdelmoneim's Railway Technology studies, automotive mechanics background, academic projects, training and contact details.

## Sections
- Profile and professional summary
- Technical expertise and skills
- Academic and independent projects
- Education, training and academic award
- Contact information

The electric train model photo is used for its matching project preview. Personal profile images are stored in `assets/`.

## Deploy to Vercel

This is a static site and needs no install or build command. From the project root, deploy with the Vercel CLI:

```sh
vercel --prod
```

When deploying through the Vercel dashboard, import the project directory, choose the **Other** framework preset, and leave the build command and output directory empty. `index.html` is served from the project root; `vercel.json` configures clean URLs, response headers, and asset caching.
